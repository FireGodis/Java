# API de saúde com Spring Boot

Eu criei uma rota pequena para praticar a estrutura de uma aplicação Java com Spring Boot e resposta JSON.

## Executar

Crie um projeto Spring Boot com Spring Web, coloque `Application.java` no pacote principal e execute pela IDE ou com Maven Wrapper.

## Endpoint

`GET /health` retorna `{"status":"ok","author":"Luiz Henrique"}`.
